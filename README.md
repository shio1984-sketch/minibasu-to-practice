# ミニバス TO練習 🏀

ミニバスケットボールの TO（テーブルオフィシャル）を練習するための Web アプリです。
試合と同じ流れで、タイマー・ショットクロック・スコアラー・アシスタントスコアラーの操作を練習できます。

## 使い方

スマホやパソコンのブラウザで、GitHub Pages の URL を開くだけで使えます（インストール不要）。
ホーム画面に追加しておくと、アプリのように起動できます。

## できること

- **実戦シミュレーション**：役割・場面・スピードを選んで、試合の流れに沿って操作を練習
- **判断ドリル**：場面を読んで正しい操作を選ぶ問題（10問ずつ）
- **ルール早見表**：TO の主なルールをすぐ確認

## 注意

- 練習用のアプリです。実際の試合では、最新の公式マニュアル・審判の指示に従ってください。
- 成績などの記録は、使っている端末のブラウザ内にだけ保存されます。
